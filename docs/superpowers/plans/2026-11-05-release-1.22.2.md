# Release 1.22.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the calendar-search and reminder-delivery fixes as LX Family 1.22.2 with a signed Android APK and consistent self-hosting package metadata.

**Architecture:** Start from the published 1.22.1 release branch and retain the two focused fixes as separate commits. Bump all locally verifiable release metadata together, build the APK through the existing signing script, and let the existing tag workflow publish the multi-architecture container before pinning stores that require its immutable digest.

**Tech Stack:** Node.js 24, Vite, Capacitor Android/Gradle, Docker Buildx via GitHub Actions, CasaOS, Umbrel and Cosmos manifests.

**Spec:** `docs/STORE_SUBMISSIONS.md`, `.github/workflows/release.yml`, `scripts/verify-release.mjs`

## Global Constraints

- Release tag, `package.json`, APK metadata and Android `versionName` must all be `1.22.2`.
- Android `versionCode` must be greater than the released 65.
- Keep the existing Android release signing key; do not commit Firebase credentials or signing material.
- CasaOS and Umbrel require the exact published GHCR digest; Cosmos remains on verified `latest` with `AuthEnabled: true`.
- Run `npm run check`, the signed APK build and `node scripts/verify-release.mjs v1.22.2` before publishing.
