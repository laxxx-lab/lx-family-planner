# LX Family 1.21.0

## Fächer auf einen Blick unterscheiden

Der Stundenplan bekommt eine größere, sorgfältig abgestimmte Auswahl aus
sechzehn Fachfarben. Eine gewählte Fachfarbe gilt für alle Stunden dieses
Fachs im jeweiligen Kinderprofil. Bereits bestehende Stunden und ihre Farben
bleiben dabei unverändert erhalten.

Die Darstellung bleibt bewusst ruhig: Jede Fachkarte erhält eine klare
Farbstreifen, einen passenden Rahmen und eine sehr leichte Hintergrundtönung.
So lassen sich Mathe, Deutsch oder Sport schneller unterscheiden, ohne dass
der Stundenplan wie ein bunter Blockplan wirkt.

Die Android-App ist in diesem Release neu signiert gebaut und lässt sich über
die vorhandene LX-App aktualisieren.
